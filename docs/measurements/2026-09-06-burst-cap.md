`bin/burst-probe 5`. Five interleaved pairs, one core (`taskset -c 0`), a fixed

Machine on AC, desktop live, agent session running.

The arms do not overlap: the slowest uncapped run (744 ms) is faster than the
fastest capped run (839 ms). Package temperature was 72–80 C throughout and did
not sort with the arms, so this is the cap, not drift.

Not measured: battery draw (the machine was charging), and any workload longer
than about a second — for which `docs/hardware.md` already records the opposite
result, that an uncapped chassis does *less* work than a capped one.

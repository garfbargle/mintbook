# Source compilation and power profiles — 2026-09-10

**Retain the existing power defaults.** This comparison does not establish a
throughput advantage for Sustained over Balanced on source compilation. It also
does not overturn the earlier four-worker awk experiment; it limits where that
result can be generalized.

`bin/workload-probe` compiled 47 Python source files from this repository,
684,645 bytes, repeatedly into in-memory code objects. It did not execute the
code, install anything, or write build output. Files were read once before the
timed work. This is a real source-compilation workload, but not an application
startup or a complete native build.

The probe ran as a transient user service at nice 0, outside any foreground GUI
process tree. On AC, it stopped `mintbook-turbo-budget.service` temporarily to
keep each cap fixed. This compares the installed profiles, including their
different energy-performance biases, rather than isolating just max_perf_pct.

Twelve single-corpus burst samples used Balanced/Sustained/Power Saver/Power
Saver/Sustained/Balanced order twice, with 1.5 seconds settling per profile.
These were unpinned, hot-desktop tasks, not cold-chip bursts.

| Profile | Median burst | Range | Samples |
|---|---:|---:|---:|
| Balanced, 100% | 851 ms | 340–998 ms | 4 |
| Sustained, 75% | 647 ms | 376–955 ms | 4 |
| Power Saver, 70% | 822 ms | 450–959 ms | 4 |

The ranges overlap heavily and the later observations are much faster. This
does not identify a short-task winner. Existing desktop use continued throughout;
the comparison cannot attribute this variation to a single cause.

For sustained work, two workers were pinned to CPUs 0 and 1 (the two physical
cores). Each arm had 10 seconds of loaded settling followed by 20 seconds of
sampling. Order was Balanced/Sustained/Sustained/Balanced/Sustained/Balanced/
Balanced/Sustained. All observed caps were correct; the probe remained at nice 0.

| Profile | Median corpus passes/s | Arm results | Mean package temperature |
|---|---:|---|---:|
| Balanced, 100% | 3.019 | 3.093, 2.944, 2.792, 3.195 | 94.44 C |
| Sustained, 75% | 2.993 | 2.390, 3.042, 3.440, 2.945 | 94.45 C |

The median difference is under 1%, inside the variation between runs. Both
profiles reached 95 C. Background desktop activity varied; CPU samples and
pressure are retained in the JSON. No energy or battery-life result was measured.
The 10-second settling interval also does not establish a chassis equilibrium.

The probe completed in 4 minutes 42 seconds, restored Balanced/100%, and restarted
the previously active turbo-budget service. The installed battery/AC/Sustained
policy and burst duration were unchanged. Interrupted-work cleanup and failed
profile-restoration cleanup have regression tests.

Raw data: [2026-09-10-workload.json](2026-09-10-workload.json).
Reproduce from the repository with:

```bash
systemd-run --user --unit=mintbook-workload-probe --collect --wait --pipe -p Nice=0 \
  /usr/bin/python3 "$PWD/bin/workload-probe" "$PWD/workload-result.json"
```
